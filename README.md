# Study OS 📚

**A personal student productivity and study-tracking system.**

Study OS is a web application built to make student life more organized. It brings study planning, task tracking, progress monitoring, and daily study goals into one workspace.

🔗 **Live Demo:** [Study OS](https://study-os-lg1h.onrender.com/)

📂 **Source Code:** [GitHub Repository](https://github.com/ArGiT69/study-os)

---

## ✨ Features

- 📊 **Study Progress Tracking** — Monitor your study progress and completed pages.
- 🔥 **Daily Streaks** — Track consistency and build better study habits.
- ✅ **Task Management** — Organize assignments and daily study tasks.
- 📚 **Subject & Goal Tracking** — Keep academic subjects and study goals organized.
- ⏱️ **Study Timer** — Support focused study sessions.
- 👥 **Friends** — Connect with friends and make studying more engaging.
- 🎨 **Themes & Customization** — Personalize the study workspace.
- 🔐 **User Accounts** — Keep track of your individual study activity.

*Features and availability may change as the project develops.*

## 🚀 Getting Started

### Prerequisites

- Python 3.10 or a compatible version
- Git
- A terminal or code editor

### 1. Clone the repository

```bash
git clone https://github.com/ArGiT69/study-os.git
cd study-os
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it on Windows:

```powershell
.\venv\Scripts\Activate.ps1
```

If you're using Command Prompt instead:

```bat
venv\Scripts\activate
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Configure environment variables

If your local setup requires environment variables, create a `.env` file in the project root and configure the values expected by the application.

**Important:** Never commit passwords, secret keys, or production database credentials to GitHub.

### 5. Run the application

Check `app.py` for the application's startup configuration and follow its local-run instructions. Once running, open the local address printed by the development server in your browser.
